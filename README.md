# علیسان | Alisan Assistant

نسخه‌ی اولیه‌ی دستیار فارسی اندروید با رابط آبی و مشکی، انیمیشن گوینده، گفتار به متن فارسی (با پشتیبانی سرویس گفتار گوشی)، خواندن پاسخ‌ها با Text-to-Speech، نوت محلی، یادآوری و لینک جست‌وجوی وب.

## ساخت APK فقط با GitHub Actions
1. فایل ZIP پروژه را از حالت فشرده خارج کن.
2. همه‌ی فایل‌ها و پوشه‌های داخل `alisan-assistant` را در ریشه‌ی یک repository جدید GitHub آپلود کن.
3. از بخش **Actions**، workflow با نام **Build Alisan APK** را اجرا کن؛ یا روی شاخه‌ی `main` پوش کن تا خودکار اجرا شود.
4. وارد اجرای موفق شو و پایین صفحه از **Artifacts** فایل `Alisan-Assistant-APK` را دانلود کن.
5. ZIP مربوط به Artifact را باز کن و `app-debug.apk` را روی گوشی نصب کن.

## امکانات فعلی
- رابط فارسی راست‌چین با تم آبی/مشکی و افکت متحرک ✨
- دکمه میکروفون و درخواست تشخیص گفتار `fa-IR`
- پاسخ صوتی با موتور گفتار گوشی (اگر صدای فارسی نصب/پشتیبانی شود)
- ذخیره‌ی نوت‌ها روی خود دستگاه
- یادآوری روزانه‌نشده برای نزدیک‌ترین زمان آینده با اعلان
- لینک جست‌وجوی وب برای عبارت‌هایی مثل «طرز تهیه ...»

## محدودیت‌های نسخه‌ی اولیه
این نسخه هنوز یک هوش مصنوعی مکالمه‌ای متصل به مدل زبانی نیست؛ پاسخ‌های عمومی محدودند و برای درخواست‌های جست‌وجویی، لینک جست‌وجوی وب باز می‌شود. تشخیص و پخش صدای فارسی به موتور گفتار و تنظیمات گوشی وابسته است. برای اعلان آلارم، اجازه‌ی اعلان‌ها را در اندروید فعال کن.
